# TJCE Study Planner ⚖️

Um planejador de estudos moderno e modular para o cargo de Técnico Judiciário do Tribunal de Justiça do Ceará (TJCE).

## ✨ Funcionalidades

- **Dashboard Inteligente**: Acompanhe sua meta diária e revisões pendentes.
- **Edital Verticalizado**: Todo o conteúdo do edital organizado por matérias e tópicos.
- **Sistema de Revisões (Spaced Repetition)**: Agendamento automático de revisões em 1, 3, 7, 15 e 30 dias.
- **Gráficos de Desempenho**: Visualize seus acertos por matéria com interface premium.
- **Design Moderno**: Interface responsiva com *Glassmorphism*, fontes Google (Outfit/Inter) e animações suaves.

## 🛠️ Tecnologias

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) (Ícones)

## 🚀 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone git@github.com:EduardoLevy/TJCE.git
   ```
2. Entre na pasta:
   ```bash
   cd TJCE
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor:
   ```bash
   npm run dev
   ```

## 📝 Nota

Os dados são salvos localmente no seu navegador (`localStorage`), garantindo que seu progresso não seja perdido ao recarregar a página.
